# plan-session

Generates a structured range session plan and writes it as a `planned`
entry in `/data/sessions.json`.

## When to use

The user asks for a session plan by focus area and (usually) a ball count,
without necessarily having used the `/sessions/plan` page themselves — or
they paste the JSON preview generated by that page and just want it saved.

## Steps

1. **Read `CLAUDE.md`** for current focus and schema, and read
   `/data/drills.json` and `/data/progress.json` to find drills and the
   canonical focus area id.
2. **Resolve the focus**: match the user's wording to an existing
   `/data/progress.json` area id where possible (e.g. "sequencing",
   "over the top", "downswing" → `sequencing-over-the-top`). If they name a
   focus with no match, use their wording as free text for `focus` — don't
   force-fit it.
3. **Pick drills**: select drills from `/data/drills.json` whose
   `target_faults` relate to the focus. Prefer 1-2 drills for the "feel
   work" block (simpler/slower drills) and the full relevant set for "drill
   work". If nothing matches well, pick general-purpose drills and say so.
4. **Build the six blocks** (warm-up, feel work, drill work, transfer,
   pressure test, cool-down) splitting the ball count roughly
   15% / 15% / 35% / 20% / 10% / 5%, rounded to the nearest 5 balls, mirroring
   the logic in `lib/data.ts`'s `generateSessionPlan`. Each block needs
   `club`, `balls`, `drills` (ids, empty array where not drill-specific), and
   a one-line `focus_note`.
5. **Write the session** to `/data/sessions.json` with a new id
   `s-YYYY-MM-DD` (today's date, or the date the user specifies), `status:
   "planned"`, empty `post_session_note` (all fields blank/null), and empty
   `stats_ids`.
6. **Validate** the file is well-formed JSON matching the schema in
   `CLAUDE.md`.
7. **Commit and push**, e.g. `Plan session: <focus>, <date>`. Routine plans
   don't need confirmation first.
8. **Reply to the user** with the block-by-block plan in plain text (not
   just "done") so they can act on it immediately.
